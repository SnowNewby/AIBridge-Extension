# AI Bridge Extension

AI Bridge Extension — браузерный клиент для удалённой работы с AI Bridge
Worker. Расширение добавляет на страницу облачного транспорта интерфейс чата,
передаёт запросы домашнему Worker и показывает ответы, статусы, терминальный
вывод и интерактивные вопросы.

Расширение предназначено для браузеров на базе Chromium и использует
Manifest V3.

## Возможности

- обычный и агентный режимы;
- живые статусы и вывод команд;
- вопросы и подтверждения действий;
- несколько чатов с отдельным контекстом;
- локальная и облачная история;
- выбор модели для каждого чата;
- прикрепление файлов;
- отдельные блоки кода с кнопкой копирования;
- локальный недельный лимит запросов;
- адаптивный интерфейс.

## Настройка Яндекс.Диска

Зарегистрируйте собственное OAuth-приложение на
[oauth.yandex.ru](https://oauth.yandex.ru/) и выдайте ему права чтения и записи
Яндекс.Диска.

Откройте `config.js` и укажите полученный `Client ID`:

```js
YANDEX_CLIENT_ID: "ваш_client_id"
```

`Client Secret` добавлять в расширение нельзя и не нужно.

В качестве Callback URI OAuth-приложения укажите:

```text
https://oauth.yandex.ru/verification_code
```

## Установка в Chromium

1. Скачайте или клонируйте репозиторий.
2. Убедитесь, что `Client ID` указан в `config.js`.
3. Откройте страницу расширений:
   - Chrome и Chromium: `chrome://extensions`;
   - Microsoft Edge: `edge://extensions`;
   - Brave: `brave://extensions`;
   - Яндекс Браузер: `browser://tune`.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное расширение**.
6. Выберите папку, внутри которой находится `manifest.json`.
7. Откройте [disk.yandex.ru](https://disk.yandex.ru/).
8. В интерфейсе AI Bridge откройте настройки и нажмите **Войти через Яндекс**.
9. После авторизации нажмите **Проверить и создать папки**.

После изменения файлов расширения откройте страницу расширений и нажмите
**Обновить** на карточке AI Bridge.

## Требования

- браузер на базе Chromium с поддержкой Manifest V3;
- собственное OAuth-приложение Яндекса;
- установленный и запущенный AI Bridge Worker;
- одинаковый аккаунт Яндекс.Диска в расширении и Worker.

Firefox в текущей версии не поддерживается.

## Правовой статус

AI Bridge — независимый экспериментальный проект. Он не разработан, не одобрен
и не поддерживается Яндексом, OpenAI или другими поставщиками интегрируемых
сервисов.

Яндекс, Яндекс.Диск, OpenAI, Codex и другие названия принадлежат соответствующим
правообладателям и упоминаются только для описания совместимости. Использование
сторонних API регулируется их действующими условиями.

Текущий адаптер использует технологию API Яндекс.Диска. Пользователь
самостоятельно регистрирует OAuth-приложение, обеспечивает сохранность токенов и
соблюдает условия сервиса.
